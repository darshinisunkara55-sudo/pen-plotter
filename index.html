First-time setup
  1. Plug in the Arduino and press Connect to Arduino.

    If the Arduino doesn't have the plotter firmware (GRBL for pins 2-13), this page installs it by itself in about 20 seconds. After the first time, the page connects on its own whenever the Arduino is plugged in.

  2. Wire the motors to the ULN2003 boards.
    MotorIN1IN2IN3IN4
    X2345
    Y6789
    Z (pen)10111213
  3. Power the boards with 5V, not 12V.

    Connect the supply's GND to the Arduino GND too.

  4. Test the motors.

    Close UGS. Open Machine setup below, press Connect to Arduino, then try each move button.

  5. Fix any motor that moves the wrong way.

    Tick Flip direction for that motor in Machine setup.

  6. Calibrate the distance.

    In Machine setup press Move X 10 mm, measure how far the pen really moved, type it in and press Fix X. Do the same for Y.

  7. Set the pen and drawing area.

    If Pen + pushes the pen into the paper, set Pen lift to -30. Set Max width and height to your machine's drawing area.

  8. Draw.

    Choose a picture, set the width to 2 cm, put the pen on the paper at the bottom-left corner and press Play.
